# Rulify 隐私政策（GitHub Pages）

此目录用于托管 App Store Connect 所需的**隐私政策网址**。

**请勿把完整 App 源码推到公开仓库。** 请使用独立公开仓库（仅含本页）：

- 公开仓库：`ffoocn/rulify-privacy`（仅 `docs/index.html`）
- 隐私政策 URL：`https://ffoocn.github.io/rulify-privacy/`
- 技术支持 URL：`https://ffoocn.github.io/rulify-privacy/support.html`

App 源码仓库 `App_Privacy` 应保持 **Private**。

## 更新隐私政策

1. 修改本目录的 [`index.html`](index.html)。
2. 同步推送到公开仓库 `rulify-privacy` 的 `docs/index.html`（不是私有源码仓库）。

## 启用 GitHub Pages（公开隐私仓库）

1. 仓库 **Settings → Pages**。
2. Branch：`main`，文件夹：**`/docs`**。
3. 将 `https://<用户名>.github.io/rulify-privacy/` 填入 App Store Connect。

## 联系我们

编辑 `index.html` 中的联系邮箱后再推送。
