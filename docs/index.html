Rulify 隐私政策

本地解析 iOS App 隐私报告，生成个人网络规则

技术支持

概述

Rulify（「本 App」）用于在您的设备上解析 iOS App 隐私报告，整理 App 与域名信息，并生成个人网络规则。 核心功能默认在本地完成，无需注册账号，也不会向 Rulify 开发者运营的服务器上传您的隐私报告。

本地处理的数据

您主动导入的 .ndjson 隐私报告（包括报告原始文件，用于删除单份报告后重建数据）、解析得到的 App 列表、域名记录、生成的规则，以及您在 App 内的偏好设置， 保存在本机的 SQLite 数据库、文件目录和系统偏好设置中。GitHub Token 与 AI 服务的 API Key 单独保存在系统钥匙串中。

上述数据用于展示、搜索、生成与导出规则，以及您配置的 GitHub 同步与 AI 复核功能。

网络功能与数据传输

本 App 包含以下网络功能：

  • App 名称与图标：展示已导入的 App 列表、详情等页面时，如本地信息缺失或过期，会自动向 Apple iTunes Lookup 接口发送对应的 Bundle ID 和查询地区，并下载公开 App 图标。查询结果缓存在本机，当前没有单独关闭此查询的设置。此功能不发送报告原文、访问域名、IP 记录或访问时间。
  • GitHub：配置仓库与 Personal Access Token 后，App 会按您的操作或已启用的自动上传设置，将生成的规则文件和提交说明发送至您指定的 GitHub 仓库。规则可能包含 App 名称、Bundle ID、域名及 IP/CIDR。公开仓库中的内容可被他人访问。
  • 仓库访问与认证：配置 GitHub 后，App 可验证连接、读取仓库路径和规则内容，用于对比与展示。Token 在本机钥匙串中保存，并在访问 GitHub API 时作为认证信息发送给 GitHub；不会发送给 Rulify 开发者。
  • AI 复核（可选，默认关闭）：在「设置 → AI 复核」中启用并填写您自己的 API Key 后，可在单个 App 的详情页手动发起复核。开始前，App 会列出将要发送的内容和接收方；只有在您点按「开始复核」后，才会把当前这一个 App 的数据直接发送给您选择的服务商（OpenAI 的 ChatGPT、Anthropic 的 Claude、DeepSeek，或您填写的 OpenAI 兼容接口）。发送内容包括：App 名称、Bundle ID 及 App 识别出的所属集团；该 App 的域名规则；每条规则覆盖的主机名，及其访问次数、是否由 App 直接发起、报告中的追踪器标记与归属方；同一根域名还有几个其它 App 访问过（只发送数量）。不发送报告原文、IP 规则和访问时间，也不发送其它 App 的名称或域名。API Key 在请求时作为认证信息发送给该服务商，不会发送给 Rulify 开发者。「测试连接」只发送一段固定的测试文字，不含报告数据。

网络服务会收到建立连接所需的信息，例如网络 IP 地址。Apple、GitHub 和您选择的 AI 服务商对收到数据的处理（包括是否保存或用于训练模型）分别受其隐私政策及您与其约定的条款约束。

删除与保留

「设置 → 清空本地数据」会删除数据库中的报告记录、本机保存的报告原始文件、App 列表、域名、规则与排除记录，并清除 App 选择、同步记录、导入状态和操作日志。 此操作不会删除尚未处理的待导入文件、名称与图标缓存、其他偏好设置、GitHub Token 或 AI 服务的 API Key。 在「已导入报告」中删除单份报告时，该报告的原始文件会一并删除。 导入时为读取报告创建的临时副本会在导入结束后自动删除；无法识别为隐私报告的待导入文件也会自动移除。

您可在「设置 → GitHub 同步 → 删除 Token」中移除本机保存的令牌，并在 GitHub 撤销该令牌；可在「设置 → AI 复核 → 删除 Key」中移除 API Key，并在对应服务商处撤销。 已导出、分享、上传到 GitHub 或发送给 AI 服务商的内容须在对应保存位置或服务中另行管理；清空本地数据不会删除这些内容。

我们不做什么

  • 不收集、不上传您的隐私报告原文至开发者服务器
  • 不提供 Rulify 账号或云端同步服务
  • 不嵌入第三方广告或行为追踪 SDK
  • 不出售您的数据
  • 不会在您手动开始复核前向任何 AI 服务发送数据

文件导入与扩展

您可通过文件选择、系统分享菜单或 Share Extension 导入报告。 分享扩展与本 App 通过 App Group 在本地传递待导入文件，数据不会经由此路径上传至外部服务器。

您的隐私报告包含什么

隐私报告由 iOS 系统生成，其中可能包含您设备上 App 的 Bundle ID、访问域名、IP 地址及时间等信息。 请在分享、导出规则、推送至 GitHub 或发起 AI 复核前，自行评估是否包含您不愿公开的内容。
