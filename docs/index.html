Rulify 隐私政策

本地解析 iOS App 隐私报告，生成个人网络规则

概述

Rulify（「本 App」）用于在您的设备上解析 iOS App 隐私报告，整理 App 与域名信息，并生成个人网络规则。 核心功能默认在本地完成，无需注册账号，也不会向 Rulify 开发者运营的服务器上传您的隐私报告。

本地处理的数据

您主动导入的 .ndjson 隐私报告、解析得到的 App 列表、域名记录、生成的规则，以及您在 App 内的偏好设置， 均保存在本机 SQLite 数据库与缓存目录中。

上述数据仅用于在本 App 内展示、搜索、导出与生成规则。您可在「设置 → 清空本地数据」中一次性删除。

可选的网络功能

除以下由您触发或可在设置中关闭/不配置的功能外，本 App 不会主动联网：

  • App 名称与图标：为改善展示效果，可能向 Apple iTunes Lookup 接口查询 Bundle ID 对应的公开 App 信息，并缓存到本机。不会上传您的隐私报告内容。
  • GitHub：仅在您于设置中填写仓库并保存 Personal Access Token 后，才会将您生成的规则文件推送至您指定的 GitHub 仓库。Token 保存在系统钥匙串，不会发送给 Rulify 开发者。
  • 规则同步：配置 GitHub 后，App 可能读取您仓库中已有规则文件路径，用于对比与展示，不会上传隐私报告。

我们不做什么

  • 不收集、不上传您的隐私报告原文至开发者服务器
  • 不提供 Rulify 账号或云端同步服务
  • 不嵌入第三方广告或行为追踪 SDK
  • 不出售您的数据

文件导入与扩展

您可通过文件选择、系统分享菜单或 Share Extension 导入报告。 分享扩展与本 App 通过 App Group 在本地传递待导入文件，数据不会经由此路径上传至外部服务器。

您的隐私报告包含什么

隐私报告由 iOS 系统生成，其中可能包含您设备上 App 的 Bundle ID、访问域名、IP 地址及时间等信息。 请在分享、导出规则或推送至 GitHub 前，自行评估是否包含您不愿公开的内容。
