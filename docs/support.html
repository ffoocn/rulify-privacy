Rulify 技术支持

在 iPhone / iPad 上解析 App 隐私报告，生成 Surge / Clash 等个人规则

隐私政策

关于 Rulify

Rulify 帮助您导入 iOS 系统导出的 App 隐私报告（.ndjson），在设备本地整理 App、域名与访问记录， 并按 ios_rule_script 风格生成、导出或同步个人网络规则。数据处理默认仅在您的设备上完成。

系统要求

  • iOS / iPadOS 16.6 或更高版本
  • 从「设置 → 隐私与安全性 → App 隐私报告」导出 .ndjson 文件
  • 可选：GitHub 账号与 Personal Access Token（用于上传规则，非必需）

快速上手

  1. 在 iOS 设置中导出 App 隐私报告（.ndjson）。
  2. 通过「文件」App、分享菜单或 Rulify 分享扩展，将报告导入 Rulify。
  3. 在「App」页查看已识别的 App 与域名；进入详情可生成规则。
  4. 在「设置」中选择导出格式、规则过滤与（可选）GitHub 仓库。
  5. 导出 .list / .yaml 规则文件，或推送至您自己的 GitHub 仓库。

常见问题

  • 导入很慢或文件很大？大型报告会在本地解析并写入 SQLite，请保持 App 在前台直至进度完成。
  • 没有生成 IP 规则？默认不生成 IP 规则（CDN 节点多为临时地址）。可在「设置 → 规则生成」中开启。
  • GitHub 上传失败？请检查 Token 权限、仓库路径与分支名；Token 仅保存在本机钥匙串。
  • 如何删除数据？在 App 内「设置 → 清空本地数据」可删除本机全部报告、域名与规则。
  • 数据会上传到开发者服务器吗？不会。详见隐私政策。
